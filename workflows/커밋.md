# /커밋

이 명령어를 실행하면 현재 변경사항을 분석하여 Conventional Commits 규칙에 맞는 커밋을 생성합니다.

## 커밋 메시지 형식

```
<type>(<scope>): <제목> (영어, 50자 이내)

- 변경 내용 상세 설명 (bullet point, 한국어)
- 필요한 경우에는 본문 작성
```

## verbose 커밋 분리 원칙

- **구현과 테스트는 별도 커밋**으로 분리
- **리팩토링과 기능 추가는 별도 커밋**으로 분리
- **모듈**의 큰 변경은 따로
- 무관한 파일(바이너리, 외부 라이브러리 등)은 커밋에서 제외
- Untracked 파일은 관련성을 확인 후 포함 여부 결정

## 일반 커밋

- **모듈** 단위로 커밋
