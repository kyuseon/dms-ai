# /문서

## 지침

- 코드에서 **직접 읽히는 내용은 문서화하지 않는다** (함수명, 변수명으로 자명한 것)
- 문서의 대상: **왜(Why)** 이 구조인지, **어떤 제약** 이 있는지, **외부 연동** 방식
- 기존 문서가 있으면 반드시 **읽고 나서** 덮어쓰거나 병합한다

## 문서 유형별 위치

| 유형 | 위치 |
|------|------|
| 모듈 설계/구조 | 해당 디렉토리의 `README.md` |
| API/인터페이스 | 헤더 파일 상단 주석 |
| 운영/배포 절차 | 루트 `README.md` 또는 `docs/` |
| AI 작업 지침 | `.airules/` |

## 작성 원칙

- 독자는 **코드를 이미 읽은 사람** 기준으로 작성
- 다이어그램보다 **텍스트 구조 설명** 우선 (유지보수 비용 최소화)
- 버전/날짜 명시는 코드로 추적 가능하면 생략
