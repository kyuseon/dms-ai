# /정리

## 지침

- 삭제 전 **git status / git log** 로 해당 파일의 이력을 확인한다
- **빌드에 포함되지 않는 파일**은 삭제 후보 — Makefile에서 참조 여부 먼저 확인
- dead code 제거 시 **해당 심볼의 모든 참조** 를 grep으로 확인 후 삭제
- 정리와 기능 변경은 **같은 커밋에 섞지 않는다**

## 우선 정리 대상

- 빌드 산출물 (`.o`, `.a`, 바이너리) — `.gitignore` 에 추가
- 이름에 `old`, `bak`, `test`, `tmp` 가 붙은 파일
- 더 이상 `#include` 되지 않는 헤더
- 주석 처리된 채 방치된 코드 블록 (작성일 3개월 초과 기준)

## 하지 말 것

- 용도 불명인 파일을 임의로 삭제 — 사용자에게 확인 후 진행
- 외부 라이브러리(`lib/ext/`) 내부 수정
- `.airules/`, `cfg/` 등 설정 디렉토리 정리는 별도 승인 필요
